# Car parts theme for Lime Street

A modern, accessible, block-based WordPress theme with native
WooCommerce support, built for the automotive parts industry.
Developed as a milestone-based probation project for Lime Street,
targeting submission to the official wordpress.org theme directory.

## Local development setup

1. Clone this repo into your local WordPress themes directory.
2. Install [WooCommerce](https://wordpress.org/plugins/woocommerce/)
   and activate this theme.
3. Run `composer install` to set up PHPCS/WPCS for coding-standards
   checks (see `phpcs.xml.dist`).

## Coding standards

This theme follows the WordPress Coding Standards. Run `vendor/bin/phpcs` to check.
